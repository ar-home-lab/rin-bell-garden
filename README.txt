りんっベルの小庭 v8

GitHub Pagesに置くための決定版パッケージです。

中身:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/
- ring_bell_lexicon_v8.txt

v8の主な機能:
- 5.5Tリューイ語録 74 個を初期内蔵
- 追加語録の追加・削除・重複整理・コピー・インポート
- 今日の庭のアイコン配置を保存
- ページを開き直しても今日の庭が残る
- 日付が変わると新しい庭になる
- 累計りんっ数を保存
- 今日の庭を整えるボタン
- PWA用 manifest / service worker / icon つき

GitHub Pagesに置く時:
1. このzipを展開します。
2. 中身をGitHubリポジトリのルートにアップロードします。
3. GitHub Pagesを main / root で有効化します。
4. 公開URLをスマホで開いて「ホーム画面に追加」します。
